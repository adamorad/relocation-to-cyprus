# RealCy — Living in Cyprus — Option 1
This kit implements the explicitly selected blue illustrated Option 1, not the previous relocation design, warm editorial design, or Option 2.

1. Unzip this folder into your existing website repository.
2. Ask your coding agent to read AGENT-PROMPT.md and inspect references/approved-desktop.png.
3. Let it adapt the supplied assets, copy and CSS to the existing application.

Included: approved desktop reference; companion mobile concept; clean neighborhood hero art; editable logo recreation and SVG interface icons; CSS tokens and responsive foundations; structured copy; route mapping template; design specification and acceptance checklist.

The mobile concept is newly derived from Option 1 and has not separately been user-approved. The desktop is the visual authority; the written responsive rules resolve conflicts. This is an implementation handoff, not application source or a deployment.

The hero is a recreation of the approved illustration. The SVG logo is a recreation, not an exact traced export. Icons are clean functional fallbacks; the six painted category illustrations and article/city photos visible in the mockup are not supplied as isolated production images. Use verified existing site photography, and maintain the selected style when illustrating categories. No font files are included.
